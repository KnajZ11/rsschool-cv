## 🛠 Новое в этом модуле (State Management)

В рамках четвертого этапа были внедрены следующие технологии и функции:

- **Глобальное состояние (Zustand):** Реализовано хранилище `useCharacterStore` для управления списком выбранных персонажей. Состояние сохраняется при навигации между страницами (пагинация не сбрасывает выбор).
- **Контекст Темы (Context API):** Реализована смена темы (Светлая/Темная) через React Context. Архитектура разделена на три изолированных слоя для обеспечения корректной работы Vite Fast Refresh, осуществлена синхронизация темы с `document.documentElement` и сохранение выбора в `localStorage`.
- **Компонент Flyout:** Панель управления выбранными элементами, жестко закрепленная внизу экрана (position: fixed) поверх контента. Отображает счетчик количества выбранных элементов в реальном времени.
- **Native CSV Export:** Выгрузка данных выбранных героев в формате CSV без использования сторонних библиотек. Использованы нативные браузерные API: `Blob`, `URL.createObjectURL`, `a.download`. Имя файла динамически включает количество элементов.
- **Логика событий:** Независимая обработка кликов. Выбор чекбокса изолирован через `e.stopPropagation()` и не вызывает переход к деталям персонажа через роутинг.
