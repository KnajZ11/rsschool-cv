# 🛰️ Rick and Morty Search App (RS School React)

Современное одностраничное приложение (SPA) для поиска и каталогизации персонажей вселенной Рика и Морти. Проект разработан в рамках прохождения курса **RS School React** и демонстрирует применение передовых подходов к управлению состоянием, кэшированию сетевых данных и строгому тестированию.

## 🛠️ Стек технологий

- **Core:** React 19, TypeScript (Strict Mode)
- **Сборщик и Среда:** Vite v8
- **Сетевой слой и Кэширование:** TanStack Query v5 (React Query)
- **Глобальный стейт:** Zustand v5

- **Стилизация:** Нативный CSS с поддержкой системных переменных (`--variables`)

## ⚡ Ключевые фичи и архитектурные решения

### 1. Декларативный сетевой слой (TanStack Query)

- **RAM-кэширование данных:** Все элементы текущей страницы пагинации и открываемые карточки персонажей автоматически кэшируются в оперативной памяти. Повторная навигация назад или клики по карточкам происходят мгновенно без повторных сетевых вызовов (0 лишней нагрузки на API).
- **Конфигурация TTL через `.env`:** Время жизни кэша (`staleTime` и `gcTime`) гибко управляется переменной окружения `VITE_CACHE_TTL`.
- **Разделение лоадеров:** Интерфейс плавно разделяет первичную загрузку (`isLoading` с анимированным спиннером) и фоновую сверку данных (`isFetching` с неблокирующим угловым индикатором).
- **Ручная инвалидация:** Реализована универсальная кнопка обновления контента. При клике метод `queryClient.invalidateQueries()` принудительно очищает оперативную память кэша и перезапускает сеть за актуальными данными.

### 2. Глобальный стейт (Zustand)

- Массив выбранных для экспорта персонажей управляется иммутабельно в независимом Zustand Store.
- Состояние отмеченных карточек полностью сохраняется и синхронизируется при пагинации, смене поисковых термов и переключении страниц роутинга.

### 3. Нативный массовый экспорт в CSV

- Нижняя панель (Flyout) активируется, если выбрана хотя бы одна карточка.
- Скачивание CSV-файла реализовано с нуля на базе нативных браузерных API (`Blob`, `URL.createObjectURL`) без привлечения тяжелых внешних библиотек, что исключает штрафы за раздувание бандла.

### 4. Изоляция темы (Context API)

- Разработан трехслойный контекст оформления (Provider, Объект контекста, кастомный хук), адаптированный для Fast Refresh без лишних перерендеров.
- Выбранная тема (светлая/темная) сохраняется в `localStorage` и бесшовно переключает CSS-переменные корневого элемента документа.

## 🚀 Команды для локального запуска

Для работы с проектом вам понадобится установленная **Node.js** (версии 20+).

1. **Клонировать репозиторий:**

    ```bash
    git clone https://github.com
    cd rsschool-cv
    ```

2. **Установить все зависимости:**

    ```bash
    npm install
    ```

3. **Настроить локальные переменные:** Создайте файл `.env` в корне проекта:

    ```env
    VITE_CACHE_TTL=300000
    ```

4. **Запустить сервер разработки (Vite локальный хост):**

    ```bash
    npm run dev
    ```

5. **Запустить тесты и собрать отчет о покрытии:**

    ```bash
    npm run test:coverage
    ```

6. **Проверить проект линтером:**

    ```bash
    npm run lint
    ```

7. **Скомпилировать Production-сборку приложения:**

    ```bash
    npm run build
    ```
