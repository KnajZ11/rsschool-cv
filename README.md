# Rick and Morty Search App (React + Vitest) 🚀

Приложение для поиска персонажей вселенной "Рик и Морти", созданное в рамках обучения в **RS School**. Проект демонстрирует работу с классовыми компонентами React, типизацию на TypeScript и глубокое юнит-тестирование.

## 📋 Реализованный функционал

### 🔍 Модули 1–5: Поиск персонажей

- **Class Components:** Стабильный классовый подход для поисковой строки и сетки персонажей.
- **LocalStorage:** Кэширование поискового запроса между сессиями пользователя.
- **ErrorBoundary:** Изоляция сбоев рендеринга с отображением Fallback UI.
- **API Mocking:** Тестирование асинхронной загрузки данных без реальных запросов к серверу.

### 📋 Модуль 6: Формы и Порталы (Isolated React Forms Application)

- **React Portals:** Универсальный изолированный компонент `Modal.tsx`, рендерящийся на уровне `document.body` для предотвращения CSS-обрезаний макета.
- **WAI-ARIA Accessibility:** Нативный алгоритм **Focus Trap** (ловушка фокуса) внутри модального окна для клавиатурной навигации (`Tab`/`Shift+Tab`) и закрытие по кнопке `Escape` строго средствами React `useRef` (без мутаций DOM).
- **Uncontrolled Form:** Неконтролируемая форма со сбором данных через объект `FormData` исключительно при сабмите для максимальной оптимизации рендеринга.
- **Controlled Form:** Управляемая форма на `React Hook Form` с валидацией в реальном времени (`mode: 'onChange'`), кастомным автокомплитом стран на стейте React и живой блокировкой кнопки отправки при наличии ошибок.
- **Zod v4 Schema Validation:** Описание жестких типов полей, включая автоматическое приведение типов, проверку совпадения паролей и заглавную первую букву имени.
- **Алгоритмический Email-валидатор:** Кастомная проверка структуры почты (одна `@`, точки в домене, без внутренних пробелов) на базе Computer Science анализа методов строк, **полностью исключающая регулярные выражения (RegEx)**.
- **FileReader API:** Асинхронное кодирование бинарных изображений (аватар профиля до 2МБ) в текстовый формат `Base64` для сохранения в стор и рендеринга.
- **Zustand v5 Store:** Накопительное ведение истории отправленных анкет в виде иммутабельного массива объектов.
- **CSS Анимация успеха:** Внедрение нативной анимации `@keyframes`, которая подсвечивает вновь созданную карточку анкеты на главной странице синим импульсом в течение 3 секунд.

## 💻 Инструкция по запуску проекта

1. Установка всех зависимостей:

   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:

   ```bash
   npm run dev
   ```

3. Проверка качества кодовой базы строгим линтером:

   ```bash
   npm run lint
   ```

4. Форматирование стилей и кода:

   ```bash
   npm run format:fix

   ```

5. Запуск модульных и интеграционных тестов:

   ```bash
   npm run test
   ```

6. Сборка детального отчета о покрытии кода (statements > 80%):

   ```bash
   npm run test:coverage
   ```

7. Локальная компиляция продакшн-бандла:

   ```bash
   npm run build

   ```
